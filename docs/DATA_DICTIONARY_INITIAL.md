# Data Dictionary (initial)

The CSV uses the following columns; descriptions should be validated against the research paper and observed values before finalizing.

| Column | Initial interpretation |
|---|---|
| `Unnamed: 0` | Index-like column; normally exclude from modeling |
| `id` | Passenger identifier; normally exclude from modeling |
| `Gender` | Passenger gender category |
| `Customer Type` | Loyal/disloyal customer category |
| `Age` | Passenger age |
| `Type of Travel` | Business or personal travel |
| `Class` | Travel cabin class |
| `Flight Distance` | Flight distance measure |
| `Inflight wifi service` | Passenger service rating |
| `Departure/Arrival time convenient` | Passenger rating |
| `Ease of Online booking` | Passenger rating |
| `Gate location` | Passenger rating |
| `Food and drink` | Passenger rating |
| `Online boarding` | Passenger rating |
| `Seat comfort` | Passenger rating |
| `Inflight entertainment` | Passenger rating |
| `On-board service` | Passenger rating |
| `Leg room service` | Passenger rating |
| `Baggage handling` | Passenger rating |
| `Checkin service` | Passenger rating |
| `Inflight service` | Passenger rating |
| `Cleanliness` | Passenger rating |
| `Departure Delay in Minutes` | Departure delay |
| `Arrival Delay in Minutes` | Arrival delay; missing values observed |
| `satisfaction` | Binary target label |

This dictionary is preliminary and should be updated after complete data profiling.
