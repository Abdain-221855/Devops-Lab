## Paper methods noted
The paper describes EDA, replacement of 393 missing arrival-delay values with the mean, a summed `TOTAL` score, PCA/factor analysis, comparisons across passenger groups, delay grouping, and binary logistic regression. It reports 87.5% overall classification accuracy for a model using original variables and 85.0% for a model based on 10 factors. These are paper-reported values, not reproduced results.

## Important caution
The dataset supplied here has 103,904 training rows. The paper describes 129,880 observations, matching the combined train/test row counts reported in the pasted notebook (103,904 + 25,976). Do not describe the single supplied CSV as the full 129,880-row dataset.
