06 · REPRODUCIBILITY

A transparent route from CSV to result.

The same Python workflow generates the tables, figures, model metrics, and this site's data payload.

01

Prepare without leakage

Identifiers are excluded. Imputation, scaling, category encoding, PCA, and model fitting stay inside pipelines learned from training data.

02

Compare two models

Logistic regression on the original predictors is compared with a 10-component PCA model using a fixed, stratified holdout.

03

Re-run locally

Install dependencies, run the workflow, then build this static showcase. No backend or passenger-level data is required at runtime.

python src/airline_satisfaction/analysis.py
npm ci
npm run build
